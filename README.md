# attenda-site

Public pages for the Yokto iOS app, served by GitHub Pages.

- `privacy/` — Privacy Policy (App Store Connect "Privacy Policy URL")
- `support/` — Support page (App Store Connect "Support URL")

Plain HTML and one stylesheet. No JavaScript, no build step, no cookies, no analytics.

Brand colours match the app icon: cream `#F3F0E1`, green `#005336`.

The repository is still named `attenda-site` on purpose. The app was renamed
from Attenda to Yokto, but these paths are the Privacy Policy and Support URLs
registered in App Store Connect, so renaming the repo would break them.
